## MEDIUM (Purpose-Gate)

5. **R-09 Badge above the H1.** Hero `Badge` with a dot sits above the headline and restates beta status. It does carry live slot data in free-beta mode, so keep it there, but the static "Beta gratis · 10 slot" and "Beta terbuka" variants are a plain eyebrow.

7. **R-04 Lucide icons in feature cards.** Icons are relevant (terminal, messages, key, database, globe), but the whole set is Lucide in identical bordered tiles. DESIGN.md mandates Lucide, so this is a direction conflict (R-37): keep or drop?
8. **R-14 Identical card shells.** Features, steps and plans all use the same `rounded-md border bg-card p-6`. Consistent with RHYTHM 1; flag only if you want more variation.
9. **R-19 Motion dial.** Fade-up on four hero elements, pulse, typing and blinking cursor at once. All are disabled under `prefers-reduced-motion`. Purpose for each should be written down; the typing and cursor are decorative.
10. **R-05 "How it works" is three numbered cards.** Matches the template pattern. The content is real (create, pay, connect), so keep if you accept the pattern.
