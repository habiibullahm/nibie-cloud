File Manager memungkinkan kamu menelusuri, mengunggah, membaca, mengubah, dan menghapus file di **volume
permanen instance-mu**.

## Batasan keamanan

- Semua operasi dibatasi pada volume permanen milikmu. Tidak ada akses ke filesystem host.
- Path divalidasi untuk mencegah traversal dan symlink yang keluar dari volume.
- Setiap aksi diautentikasi dan kepemilikan tenant diverifikasi di server.
- Browser tidak pernah mengirim ID container, path host, atau parameter Docker.
