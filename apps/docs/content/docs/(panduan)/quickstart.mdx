<Callout type="info" title="Draft">
Alur ini mengikuti rancangan produk. Pembayaran dan beberapa langkah dashboard belum aktif di tahap
private beta, jadi tampilannya bisa berbeda saat dirilis.
</Callout>

<Steps>
<Step>

### Daftar dan verifikasi akun

Buat akun di dashboard Nibie Cloud, lalu verifikasi emailmu.

</Step>
<Step>

### Pilih paket dan beri nama instance

Pilih paket hosting (batas CPU, RAM, dan penyimpanan ditampilkan jelas), lalu beri nama instance. Nama
hanya untuk memudahkanmu mengenali instance.

</Step>
<Step>

### Tinjau ringkasan dan bayar

Periksa spesifikasi, siklus tagihan bulanan, dan harga. Bayar lewat metode yang tersedia (termasuk QRIS bila
didukung). Instance baru dibuat setelah pembayaran diverifikasi oleh server, bukan hanya dari halaman
redirect.

</Step>
<Step>

### Tunggu provisioning

Dashboard menampilkan progres: instance dibuat, volume penyimpanan disiapkan, lalu Hermes dijalankan dan
dicek kesehatannya. Statusnya berubah dari `Provisioning` ke `Starting` lalu `Active`. Lihat
[status instance](/instance-dan-status).

</Step>
<Step>

### Atur penyedia AI dan Telegram

Pilih [NibieRouter atau API key sendiri](/provider-ai), lalu [hubungkan bot Telegram](/telegram) milikmu.

</Step>
<Step>

### Mulai pakai

Buka halaman **Access** untuk cara mengakses instance, dan kelola sisanya dari dashboard. Lihat
[Kelola instance](/kelola-instance).

</Step>
</Steps>
