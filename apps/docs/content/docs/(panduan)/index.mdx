Nibie Cloud adalah layanan hosting terkelola untuk agen AI Hermes.
Kamu mendapat satu container Hermes yang khusus dan terisolasi, plus penyimpanan permanen, tanpa harus mengurus
VPS, Docker, deployment, atau pemeliharaan server.

Prinsip kerjanya: **kamu yang mengatur agen, Nibie Cloud yang mengurus infrastrukturnya.**

## Yang kamu dapat

- **Instance khusus.** Satu container Hermes per pelanggan, dengan penyimpanan permanen sendiri.
- **Akses penuh ke instance-mu.** Pakai semua fitur dan tool Hermes, pasang skill kustom, dan buka shell
  di dalam container-mu sendiri. Tidak ada akses SSH ke server host.
- **Dashboard satu pintu.** Deploy, pantau, lihat log, kelola file, dan atur konfigurasi dari satu tempat.
- **Infrastruktur otomatis.** Pemantauan kesehatan, pemulihan otomatis, backup, dan pembaruan runtime
  dikelola oleh Nibie Cloud.
- **Telegram.** Hubungkan bot Telegram milikmu supaya bisa berbicara dengan agen dari ponsel.
- **Pilihan penyedia AI.** Pakai NibieRouter sebagai default, atau bawa API key sendiri (BYOK).

## Biaya hosting dan biaya AI terpisah

Nibie Cloud hanya menagih **langganan hosting**. Pemakaian token AI ditagih terpisah, lewat NibieRouter atau
lewat penyedia yang kamu pilih sendiri. Paket hosting tidak menyertakan token dan tidak menjanjikan pemakaian
AI tanpa batas.

## Yang bukan produk ini

Nibie Cloud adalah hosting Hermes terkelola. Di tahap awal ini bukan platform orkestrasi multi-agent,
bukan marketplace skill, bukan VPS serbaguna, dan tidak memberi akses SSH atau Docker ke server host.
