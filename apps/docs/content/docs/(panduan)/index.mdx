Nibie Cloud adalah layanan hosting terkelola untuk agen AI Hermes.
Kamu mendapat satu container Hermes yang khusus dan terisolasi, plus penyimpanan permanen, tanpa harus mengurus
VPS, Docker, deployment, atau pemeliharaan server. Kamu mengatur agennya; Nibie Cloud menjalankan dan memantau
container-nya.

## Yang sudah bisa kamu pakai

Setiap pelanggan mendapat satu container Hermes dengan penyimpanan permanen sendiri. Dari dashboard kamu bisa
membuat instance, melihat statusnya, menyalakan, menghentikan, memulai ulang, dan menghapusnya, serta membaca
log container dengan kredensial yang disamarkan.

Agenmu tersambung ke Telegram lewat bot milikmu sendiri. NibieRouter dipasang otomatis sebagai penyedia AI,
dan kamu bisa menggantinya dengan API key sendiri. Bila container crash, Nibie Cloud mencoba memulainya lagi
secara otomatis.

## Yang menyusul

Fitur berikut belum tersedia di dashboard. Halamannya di dokumentasi ini menjelaskan rancangannya dan ditandai
**Draft**.

- [Web Console](/web-console) (shell di dalam container) dan [File Manager](/file-manager).
- Halaman Monitor (grafik CPU, memori, dan disk), halaman Access, dan halaman Backups.
- [Custom domain](/custom-domain).
- Ganti paket (upgrade atau downgrade).
- Laporan pemakaian AI di dashboard.
- Platform pesan selain Telegram. Hermes sendiri mendukung banyak platform, tetapi dashboard baru menyambungkan
  Telegram.

## Biaya hosting dan biaya AI

Nibie Cloud menagih **langganan hosting**. Pemakaian token AI ditagih terpisah, lewat NibieRouter atau
lewat penyedia yang kamu pilih sendiri. Paket Hosting tidak menyertakan kredit AI. Paket Hosting + Kredit AI
menyertakan kredit NibieRouter US$2 satu kali di awal, bukan setiap bulan. Tidak ada paket yang menjanjikan
pemakaian AI tanpa batas.

## Yang bukan produk ini

Nibie Cloud adalah hosting Hermes terkelola. Di tahap awal ini bukan platform orkestrasi multi-agent,
bukan marketplace skill, bukan VPS serbaguna, dan tidak memberi akses SSH atau Docker ke server host.
