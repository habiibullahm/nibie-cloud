---
title: Instance dan status
description: Apa itu instance, dan arti setiap status yang tampil di dashboard.
---

Satu **instance** adalah satu container Hermes yang khusus untukmu, dengan satu volume penyimpanan
permanen. Container dan volume itu tidak dipakai bersama pelanggan lain.

Setelah dibuat, instance tetap ada di antara restart. Data di volume-mu (konfigurasi, file, skill) bertahan
walau container dimulai ulang atau dipulihkan.

## Status instance

| Status | Artinya | Yang bisa kamu lakukan |
| --- | --- | --- |
| `Pending` | Permintaan diterima dan masuk antrean. | Menunggu. |
| `Provisioning` | Container dan volume sedang dibuat, lalu pengaturan awal diterapkan. | Menunggu, progres terlihat di halaman Overview. |
| `Starting` | Hermes dijalankan dan dicek kesehatannya. | Menunggu. |
| `Active` | Instance sehat dan siap dipakai. | Pakai Hermes, restart, stop, atau hapus. |
| `Degraded` | Hermes berjalan tetapi gagal dicek kesehatannya. Nibie Cloud mencoba memulihkan otomatis. | Baca alasan yang ditampilkan dan periksa **Logs**. Bila terus terjadi, restart instance. |
| `Stopping` | Container sedang dihentikan. Data tetap disimpan. | Menunggu. |
| `Stopped` | Container berhenti, karena kamu menekan **Stop** atau karena langganan di-suspend. Data tetap disimpan. | **Start** bila kamu yang menghentikannya. Bila langganan di-suspend, [perpanjang langganan](/siklus-langganan). |
| `Failed` | Pembuatan atau pemulihan instance gagal. | Hapus instance ini lalu deploy yang baru. Bila terus gagal, hubungi [bantuan](/bantuan). |
| `Deleting` | Instance dan datanya sedang dihapus. | Tidak ada. |
| `Deleted` | Instance sudah dihapus. | Tidak ada. |

Untuk setiap masalah, dashboard menampilkan alasan singkat yang tidak memuat data sensitif.

**Suspended** bukan status instance, melainkan status langganan berbayar. Saat langganan di-suspend, instance
dihentikan (statusnya `Stopped`), tombol **Start** disembunyikan, dan setiap halaman instance menampilkan
pemberitahuan dengan tombol untuk memperpanjang. Lihat [Siklus langganan](/siklus-langganan).

## Pemulihan otomatis

Bila container crash, Nibie Cloud mencoba memulainya lagi dengan jeda yang makin panjang (maksimal 3 percobaan
berturut-turut). Jika tetap gagal, status menjadi `Degraded` dan tim kami diberi tahu.

Gangguan di sisi penyedia model AI **tidak** memicu restart. Hermes yang sehat tidak dimulai ulang hanya
karena penyedia AI sedang bermasalah. Lihat [Provider AI](/provider-ai#bila-penyedia-ai-bermasalah).

Instance yang kamu hentikan sendiri (`Stopped`) tidak pernah dinyalakan ulang secara otomatis.

## Aksi pada instance

Restart, stop, start, dan hapus dijelaskan di [Kelola instance](/kelola-instance#aksi-instance).
