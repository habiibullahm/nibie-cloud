Onboarding sepenuhnya mandiri dan infrastruktur berjalan otomatis. Untuk tahap awal, dukungan diberikan
lewat **Telegram**: hubungi [@abib_mohd](https://t.me/abib_mohd). Komunitas Telegram
direncanakan menyusul dan bukan bagian dari peluncuran awal.

## Sebelum menghubungi

Sertakan hal berikut supaya penanganan lebih cepat:

- Nama instance dan statusnya di dashboard.
- Alasan yang ditampilkan dashboard, bila ada.
- Perkiraan waktu masalah mulai terjadi.

Jangan pernah mengirim API key, token bot, atau kata sandi ke siapa pun, termasuk lewat chat dukungan.
