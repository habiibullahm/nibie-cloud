## Masalah yang sering muncul

| Masalah | Coba ini |
| --- | --- |
| Kode verifikasi tidak masuk | Periksa folder spam, lalu tekan **Send a new code** setelah 60 detik. Lihat [Quickstart](/quickstart). |
| Halaman Deploy menampilkan **No plan is open for your account** | Slot beta gratis sedang penuh. [Masuk daftar tunggu](/quickstart#bila-slot-gratis-habis). |
| Bot Telegram tidak membalas | Pastikan kamu sudah menekan **Start** di bot, ID-mu ada di **Allowed users**, dan instance sudah di-restart setelah menyimpan. Lihat [Telegram](/telegram). |
| Agen tidak menjawab, tab **AI provider** kosong | Tunggu beberapa menit setelah instance `Active`. Bila tetap kosong, pasang [API key sendiri](/provider-ai#byok-bawa-api-key-sendiri). |
| Status `Degraded` | Buka **Logs**, lalu restart instance. Lihat [Instance dan status](/instance-dan-status). |
| Status `Failed` | Hapus instance itu lalu deploy yang baru. |

## Menghubungi kami

Semua saluran kontak ada di halaman [Kontak](https://cloud.nibie.app/kontak).

Sertakan hal berikut supaya penanganan lebih cepat:

- Alamat email akunmu.
- Nama instance dan statusnya di dashboard.
- Alasan yang ditampilkan dashboard, bila ada.
- Perkiraan waktu masalah mulai terjadi.

Jangan pernah mengirim API key, token bot, atau kata sandi ke siapa pun, termasuk lewat chat dukungan.
