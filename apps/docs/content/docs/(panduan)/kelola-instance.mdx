Buka **Instances** di dashboard, lalu pilih instance-mu. Menu di bawah nama instance berisi halaman berikut.

| Menu | Fungsi |
| --- | --- |
| **Overview** | Status Hermes, progres saat deploy, kartu **Health** (runtime, gateway Hermes, penyedia AI, Telegram), dan riwayat aktivitas. |
| **Logs** | Output container instance-mu, dengan kredensial instance yang disamarkan. |
| **Configuration** | Tab **Telegram**, **AI provider**, dan **Runtime**. Lihat [Telegram](/telegram) dan [Provider AI](/provider-ai). |
| **Upgrade & renew** | Status langganan, perpanjangan, dan pembatalan untuk instance berbayar. Lihat [Siklus langganan](/siklus-langganan). |

<Callout type="warn" title="Draft: belum tersedia">
Menu **Access**, **Monitor**, **File manager**, **Console**, **Backups**, dan **Custom domain** belum tersedia
selama beta. Bila kamu membuka alamatnya langsung, dashboard menampilkan **Not available in the beta yet**.
</Callout>

## Aksi instance

Tombolnya ada di bagian atas halaman instance, di samping nama dan status. Yang muncul bergantung pada status instance.

| Aksi | Kapan tersedia | Yang terjadi |
| --- | --- | --- |
| **Restart** | `Active` atau `Degraded` | Hermes dimulai ulang. Pengaturan Telegram dan provider yang baru disimpan ikut diterapkan. |
| **Stop** | `Active` atau `Degraded` | Container berhenti, data di volume tetap disimpan. |
| **Start** | `Stopped` | Container berjalan lagi dengan data yang sama. |
| **Delete** | `Active`, `Degraded`, `Stopped`, atau `Failed` | Instance dan datanya dihapus. Untuk instance berbayar, langganannya ikut berakhir. |

Selama status sedang berpindah (misalnya `Provisioning` atau `Stopping`), tombol aksi tidak tersedia sampai prosesnya
selesai.

Dashboard tidak pernah menampilkan path filesystem host, akses socket Docker, kredensial host, atau detail jaringan
internal.
