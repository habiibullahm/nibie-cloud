title: Custom domain

---

<Callout type="warn" title="Draft: belum diputuskan">
Custom domain adalah fitur opsional dan bergantung pada cara lalu lintas web diarahkan ke instance. Apakah fitur
ini tersedia dan di paket mana belum diputuskan.
</Callout>

Bila didukung, kamu akan menambahkan domain di menu **Custom domain**, membuat catatan DNS yang diminta,
lalu menunggu verifikasi. Petunjuk DNS yang tepat akan ditulis di sini setelah rancangannya final.
