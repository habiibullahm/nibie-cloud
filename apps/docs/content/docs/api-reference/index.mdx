<Callout type="warn" title="Belum ada token untuk skrip">
API di bagian ini sudah berjalan: inilah API yang dipakai dashboard. Setiap permintaan butuh token sesi login
dashboard. Belum ada cara membuat token khusus untuk skrip atau otomasi, jadi API ini belum ditawarkan untuk
dipakai di luar dashboard. Bentuk permintaan dan respons masih bisa berubah selama beta.
</Callout>

## Base URL

```text
https://api.cloud.nibie.app/api/v1
```

Semua path di bagian ini relatif terhadap base URL tersebut.

## Prinsip API

- Aksi yang berjalan lama (membuat instance, start, stop, restart, hapus) mengembalikan `202 Accepted`.
  Status akhir diambil lewat endpoint status.
- Setiap akses diperiksa terhadap akunmu. Mengakses instance milik akun lain mengembalikan `404`, bukan `403`.
- Aksi yang sensitif terhadap duplikasi (membuat instance, memulai pembayaran) memakai
  [idempotency key](/api-reference/error-dan-idempotensi).
- Galat selalu disanitasi dan tidak pernah memuat secret atau kredensial infrastruktur.
- Setiap pengguna dibatasi 120 permintaan per menit, dengan batas lebih ketat untuk membuat instance, memulai
  pembayaran, dan menguji Telegram atau provider.
- Respons memakai `Cache-Control: no-store`.
