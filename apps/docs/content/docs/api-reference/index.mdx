## Base URL

```text
https://api.cloud.nibie.app/api/v1
```

Semua path di bagian ini relatif terhadap base URL tersebut.

## Prinsip API

- Aksi yang berjalan lama (provisioning, restart, restore, dan sejenisnya) mengembalikan `202 Accepted`.
  Status akhir diambil lewat endpoint status.
- Setiap akses sumber daya diverifikasi per tenant. Mengakses instance milik tenant lain mengembalikan
  `404`, bukan `403`.
- Aksi yang sensitif terhadap duplikasi (membuat instance) memakai [idempotency key](/api-reference/error-dan-idempotensi).
- Galat selalu disanitasi dan tidak pernah memuat secret atau kredensial infrastruktur.
- Autentikasi, console, file, dan provisioning dikenai rate limit.
- Respons memakai `Cache-Control: no-store`.
