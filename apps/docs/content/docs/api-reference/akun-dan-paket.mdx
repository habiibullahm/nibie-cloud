## GET /me

Mengembalikan akun yang sedang login.

```bash
curl https://api.cloud.nibie.app/api/v1/me \
  -H "Authorization: Bearer <TOKEN_SESI_LOGIN>"
```

```json
{
  "id": "…",
  "email": "kamu@contoh.id",
  "tenantId": "…"
}
```

Saat permintaan terverifikasi pertama kali, akun dan tenant pribadimu dibuat otomatis. `tenantId` adalah ID
ruang milikmu tempat instance disimpan.

## GET /plans

Mengembalikan semua paket yang aktif, beserta batas sumber dayanya. Field `available` menunjukkan apakah akunmu bisa
memilih paket itu sekarang:

- Paket beta gratis (tanpa harga) tersedia bila akunmu sudah diundang ke beta, selama slot gratis masih ada, atau bila
  kamu punya undangan dari daftar tunggu yang masih berlaku.
- Paket berbayar tersedia setelah pembayaran dibuka.

Paket dengan `available: false` tampil di dasbor dengan tanda "Stock 0" dan tidak bisa dipilih.

```json
{
  "plans": [
    {
      "id": "…",
      "slug": "…",
      "name": "…",
      "cpuMillis": 1000,
      "memoryMb": 1024,
      "storageMb": 5120,
      "pids": 256,
      "monthlyPriceIdr": null,
      "includedCreditUsd": null,
      "available": true
    }
  ]
}
```

| Field | Arti |
| --- | --- |
| `cpuMillis` | Kuota CPU dalam milli-core (1000 = 1 core). |
| `memoryMb` | Batas memori dalam MB. |
| `storageMb` | Kuota penyimpanan permanen dalam MB. |
| `pids` | Batas jumlah proses. |
| `monthlyPriceIdr` | Harga bulanan dalam rupiah. `null` berarti paket tanpa harga, yaitu paket beta gratis. |
| `includedCreditUsd` | Kredit NibieRouter dalam US$ yang diberikan bersama setiap pembayaran periode, atau `null` bila tidak ada. |
| `available` | `true` bila akunmu bisa memilih paket ini sekarang; `false` berarti stoknya habis untukmu. |

Angka pada contoh hanya menunjukkan bentuk respons.
