## GET /me

Mengembalikan akun yang sedang login.

```bash
curl https://api.cloud.nibie.app/api/v1/me \
  -H "Authorization: Bearer <TOKEN_SESI_LOGIN>"
```

```json
{
  "id": "…",
  "email": "kamu@contoh.id",
  "tenantId": "…"
}
```

Saat permintaan terverifikasi pertama kali, akun dan tenant pribadimu dibuat otomatis. `tenantId` adalah ID
ruang milikmu tempat instance disimpan.

## GET /plans

Mengembalikan paket yang bisa kamu pilih saat ini, beserta batas sumber dayanya. Isinya bergantung pada akunmu:

- Paket beta gratis (tanpa harga) muncul selama slot gratis masih ada, atau bila kamu punya undangan dari daftar
  tunggu yang masih berlaku.
- Paket berbayar muncul setelah pembayaran dibuka.

Daftar kosong berarti belum ada paket yang terbuka untukmu.

```json
{
  "plans": [
    {
      "id": "…",
      "slug": "…",
      "name": "…",
      "cpuMillis": 1000,
      "memoryMb": 1024,
      "storageMb": 5120,
      "pids": 256,
      "monthlyPriceIdr": null,
      "includedCreditUsd": null
    }
  ]
}
```

| Field | Arti |
| --- | --- |
| `cpuMillis` | Kuota CPU dalam milli-core (1000 = 1 core). |
| `memoryMb` | Batas memori dalam MB. |
| `storageMb` | Kuota penyimpanan permanen dalam MB. |
| `pids` | Batas jumlah proses. |
| `monthlyPriceIdr` | Harga bulanan dalam rupiah. `null` berarti paket tanpa harga, yaitu paket beta gratis. |
| `includedCreditUsd` | Kredit NibieRouter dalam US$ yang diberikan satu kali bersama pembayaran pertama, atau `null` bila tidak ada. |

Angka pada contoh hanya menunjukkan bentuk respons.
