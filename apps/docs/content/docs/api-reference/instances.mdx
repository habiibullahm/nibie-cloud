## Objek instance

```json
{
  "id": "…",
  "tenantId": "…",
  "name": "agen-pribadi",
  "status": "ACTIVE",
  "statusReason": null,
  "accessUrl": null,
  "createdAt": "2026-11-12T10:00:00.000Z"
}
```

| Field | Arti |
| --- | --- |
| `id` | ID instance. |
| `name` | Nama yang kamu berikan. |
| `status` | Status instance. Lihat [status instance](/instance-dan-status). |
| `statusReason` | Alasan yang tidak sensitif bila ada masalah, atau `null`. |
| `accessUrl` | URL akses. Sementara masih alamat lokal sampai ingress subdomain tersedia, jadi jangan tampilkan ke pengguna sebagai URL sungguhan. |
| `createdAt` | Waktu dibuat (ISO 8601). |

Nilai `status` di API memakai huruf besar: `PENDING`, `PROVISIONING`, `CONFIGURING`, `STARTING`,
`ACTIVE`, `DEGRADED`, `STOPPING`, `STOPPED`, `FAILED`, `DELETING`, `DELETED`. `CONFIGURING` adalah tahap singkat
setelah `PROVISIONING`; dashboard menampilkannya sebagai Provisioning.

## POST /instances

Membuat instance. Memerlukan header [`Idempotency-Key`](/api-reference/error-dan-idempotensi#idempotency-key).

| Body | Tipe | Keterangan |
| --- | --- | --- |
| `name` | string | Nama instance. |
| `planId` | string | ID dari `GET /plans`. |

Body diperiksa ketat: field lain ditolak.

Respons `202 Accepted`:

```json
{ "instance": { "id": "…", "status": "PENDING", "…": "…" }, "jobId": "…" }
```

`jobId` adalah ID pekerjaan di antrean, atau `null` bila pekerjaan langsung dijalankan.

Lewat endpoint ini kamu hanya bisa membuat instance di **paket beta gratis**. Instance berbayar dibuat otomatis
setelah pembayaran terverifikasi, lewat [langganan](/api-reference/langganan).

| Respons | Kapan |
| --- | --- |
| `403 provisioning_not_enabled` | `planId` bukan paket beta gratis, atau beta gratis sedang tidak dibuka. |
| `409 beta_full` | Slot beta gratis habis. Masuk daftar tunggu di cloud.nibie.app. Undangan yang masih berlaku menyimpan slot untukmu. |
| `409 capacity_full` | Server sedang penuh. Coba lagi nanti. |
| `409 instance_limit_reached` | Akunmu sudah mencapai batas jumlah instance. |
| `429 rate_limited` | Lebih dari 5 permintaan membuat instance dalam 10 menit. |

Mengulang permintaan dengan `Idempotency-Key` yang sama untuk instance yang sudah dibuat tidak pernah ditolak
karena slot atau kapasitas penuh.

## GET /instances

Daftar instance milik tenant-mu.

```json
{ "instances": [ { "id": "…", "name": "agen-pribadi", "status": "ACTIVE", "…": "…" } ] }
```

## GET /instances/:id

Satu instance. Respons: `{ "instance": { … } }`.

## GET /instances/:id/status

Ringkasan status:

```json
{ "status": "ACTIVE", "statusReason": null, "accessUrl": null }
```

Gunakan endpoint ini untuk polling setelah aksi yang mengembalikan `202`.

## GET /instances/:id/events

Riwayat perubahan status instance. Respons: `{ "events": [ … ] }`.

## Aksi siklus hidup

| Endpoint | Fungsi |
| --- | --- |
| `POST /instances/:id/start` | Menyalakan instance yang berhenti. |
| `POST /instances/:id/stop` | Menghentikan instance. |
| `POST /instances/:id/restart` | Memulai ulang instance. |
| `DELETE /instances/:id` | Menghapus instance. |

Semuanya mengembalikan `202 Accepted` dengan `{ "instance": { … }, "jobId": … }`. Aksi yang tidak cocok dengan
status saat ini (misalnya start pada instance yang `ACTIVE`) mendapat `409 conflict`. Perubahan status diproses
dengan aman terhadap permintaan yang berbarengan: bila aksimu kalah bersaing dengan aksi lain pada instance yang
sama, kamu juga mendapat `409 conflict`.

Untuk instance berbayar yang langganannya di-suspend, `start` dan `restart` mendapat
`409 subscription_suspended`. Instance itu kembali hanya lewat perpanjangan. Menghapus instance berbayar ikut
mengakhiri langganannya.

Mengakses instance tenant lain pada semua endpoint di atas selalu menghasilkan `404`.
