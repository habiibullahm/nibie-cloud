# antislop audit 001 (2026-11-12)

Scope: `apps/web` (Hermes Cloud dashboard) at `main@6e5d644`.
Tool: `antislop-ai@3.2.29` rule sets (core, ui, human, layoutmobile, copywriting), applied in
**after** mode: audit first, then fix only approved numbers. Nash approved fixing the findings on
2026-11-12. Results are in [report-001-2026-11-12.md](report-001-2026-11-12.md).

titles, rendered em dashes, overflow), and `contrast-check.py` over every token pairing.

Priority follows the rule tier: Hard Gate = HIGH, Purpose-Gate = MEDIUM, Quality Locks = LOW.

## Checked and passing

- Text contrast: every text pairing passes AA. Lowest is muted `#9CA3AA` on secondary surface `#24292E` at 5.75:1; white on terracotta is 4.84:1; white on destructive 5.10:1.
- Non-text contrast: `border-strong` against page, card and elevated (4.09, 3.78, 3.48), the terracotta fill (4.02 on page) and the focus ring (17.69) all pass 3:1.
- Disabled text is 2.26:1, which WCAG exempts for inactive controls.
- No horizontal overflow at 390px on any route; one `h1` per page, no skipped heading levels, `lang` set, no `user-scalable=no`.
- No gradients, glass, glow, shadow stacks, emoji, bento grid, fake terminal, testimonials or invented people. The mock user is "Preview user / you@example.com".
- Status never relies on color: each badge has a text label and its own icon shape.
- Focus ring visible on every control; dialogs close with Escape; skip link present.
