## Ponytail review

1. **Disabled fields still reacted to hover** (input, textarea, select, checkbox, switch). Removing
   `pointer-events-none` so disabled controls can show `not-allowed` let the hover border through.
   Fixed with `enabled:hover:`.
2. **Monitor reported the same failure twice.** The charts area now only shows loading and leaves the
   error to the stats block.
3. **Dead CSS selector** `label[data-disabled="true"]` nothing sets. Removed.

## Final audit

The click-through found two bugs that were already on `main`:

- **Leaving the Console page crashed the app** ("i is not a function"). The scroll effect returned
  the value of `scrollIntoView`, which is a Promise in current Chromium, and React called it as the
  cleanup. Fixed with a block body.
- **"URL copied" showed even when the clipboard refused.** Copy now awaits the write and says when it
  failed (`src/lib/copy.ts`).

Re-run after the fixes, at 390px with touch emulation and at 1440px, over all 16 routes:

- No control under 44x44px on touch (the skip link included), no missing pointer cursor, no em dash,
  no decorative arrow, no horizontal overflow, no console errors.
- Contrast unchanged: every text pairing passes AA (lowest 4.84:1, white on terracotta).
